生き急ぎタイマー

今日は、あと何秒？

16,140秒

「4時間29分」ではなく、「あと16,140秒」。

「あと数時間」「あと1日」と考えると、時間はたっぷりあるように感じてしまいます。生き急ぎタイマーは、1日の終わりや自分で決めた締め時刻までの残り時間を、分か秒の1つの単位だけで表示して、時間が貴重であることを思い出させてくれるiPhoneアプリです。

できること

  • 1日の終わりまでの残り時間を、分または秒で表示
  • 締め時刻は自由に設定。就寝時刻、終業時刻、締め切りなど、自分の区切りに合わせられます
  • 数字をタップして、分と秒の表示を切り替え
  • 残り1分を切ると、自動で秒表示に切り替え
  • 毎日繰り返すか、特定の日時まで1回だけ数えるかを選択
  • タイマーのタイトルも自由に変更
  • ホーム画面・ロック画面・StandByのウィジェット
  • ライト／ダーク／濃紺のテーマ

よくある質問

締め時刻を過ぎるとどうなりますか？
「毎日」の場合は、翌日の同じ時刻までのカウントを自動で始めます。「1回のみ」の場合は、カウントを終了します。
締め時刻を深夜にできますか？
できます。たとえば2:00に設定すると、23:00の時点では「あと180分」と、翌日2:00までの時間を表示します。
海外にいるときの時刻はどうなりますか？
iPhoneのタイムゾーン設定に合わせて自動で計算します。
データはどこに保存されますか？
設定内容はお使いのiPhoneの中にだけ保存され、外部には送信されません。詳しくはプライバシーポリシーをご覧ください。
